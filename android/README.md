# 📱 Argus Android Application

> Автономный мобильный ассистент компьютерного зрения для незрячих и слабовидящих пользователей на базе CameraX, MediaPipe Tasks и ML Kit.

Android-приложение системы **Argus** в реальном времени анализирует видеопоток с камеры смартфона, распознает 10 целевых классов физических препятствий COCO (`person`, `chair`, `dining table`, `bench`, `backpack`, `suitcase`, `potted plant`, `car`, `bicycle`, `dog`) и опасные элементы окружения (лестницы, стены, дверные проемы, мебель и подлокотники), объединяет их с данными сонара и гироскопа трости по Bluetooth SPP и озвучивает русские голосовые подсказки.

Все нейросетевые вычисления и геометрическая фильтрация выполняются **локально на устройстве** без обращения к внешним серверам и без необходимости подключения к интернету. Приложение входит в состав общего репозитория Argus и может работать как самостоятельно, так и в паре с аппаратной тростью.

## Статус проекта

Текущая стадия: активная разработка (**версия 1.0, versionCode 1**).

| Функция | Реализация | Состояние |
|:---|:---|:---:|
| **Видеопоток с камеры** | CameraX ImageAnalysis (YUV_420_888, ~5.5 FPS) | Реализовано |
| **Детекция объектов (10 классов COCO)** | MediaPipe Tasks Vision (EfficientDet-Lite0 int8, ~4.4 МБ) с белым списком 10 навигационных классов | Реализовано |
| **Классификация окружения (сцены)** | Google ML Kit Image Labeling (порог 0.40) | Реализовано |
| **Приоритизация угроз и Sensor Fusion** | Единая 5-уровневая иерархия (`EvaluateHazardsUseCase` + `EvaluateSensorFusionUseCase` + `MainViewModel`) | Реализовано, покрыто тестами |
| **Озвучивание подсказок** | Android Text-to-Speech (`ru-RU` с системным фолбэком, кулдаун 4 с на повторы) | Реализовано |
| **Прием телеметрии с трости по Bluetooth SPP** | Односторонний прием пакетов от `HC-05`/`HC-06`/`ARGUS` (`DIST:<см>,DIR:<курс>`) + локальный демо-режим | Реализовано, покрыто тестами |
| **Тактильный виброотклик смартфона** | Haptic feedback при критических угрозах | Запланировано |

## Возможности

- **Обработка потока в реальном времени**: анализ кадров с адаптивным пропуском при отставании (`STRATEGY_KEEP_ONLY_LATEST`) с частотой около 5-6 кадров в секунду и явным освобождением `Bitmap`/`MPImage`.
- **Детекция 10 целевых классов COCO**: определение значимых навигационных препятствий (`person`, `chair`, `dining table`, `bench`, `backpack`, `suitcase`, `potted plant`, `car`, `bicycle`, `dog`) с переводом названий на русский язык (`ObstacleTranslator`).
- **Разделение на пространственные зоны**: классификация препятствий по горизонтальным секторам (`LEFT`, `CENTER`, `RIGHT`) и трем категориям дистанции (`NEAR >= 28%`, `MEDIUM 12%-28%`, `FAR 6%-12%`).
- **Распознавание опасных элементов инфраструктуры**: специализированный классификатор лестниц, глухих стен, открытых дверных проемов и посадочных мест (`HazardClassifier`).
- **Sensor Fusion и строгая 5-уровневая иерархия безопасности**: объединение данных ультразвукового сонара и угла наклона трости со зрением камеры; срочные предупреждения (сонар `< 35 см`, лестница, боковой конфликт, стена, препятствие вплотную) прерывают текущую речь.
- **Локальный демо-режим для проверки и защиты**: кнопка `"ТЕСТ / КАЛИБРОВКА"` при отсутствии подключенной трости пытается подключиться к сопряженному устройству `HC-05`/`HC-06`/`ARGUS`, а при его недоступности запускает локальную демонстрационную последовательность телеметрии на телефоне без отправки команд в сокет.
- **Полная автономность и приватность**: нулевой сетевой трафик, локальная обработка кадров в оперативной памяти без записи на диск.

## Установка и запуск

### Android Studio

1. Откройте каталог `android/` через меню **File -> Open**.
2. Дождитесь окончания синхронизации Gradle и загрузки зависимостей.
3. Подключите реальное Android-устройство по USB (включите режим "Отладка по USB" в настройках разработчика) либо запустите эмулятор с эмуляцией задней камеры (**VirtualScene** или **Webcam**).
4. Выберите модуль `app` в списке конфигураций и нажмите **Run** (`Shift + F10`).

### Командная строка

Сборка Debug APK и установка на подключенное устройство:

```bash
# Перейдите в каталог проекта
cd android

# Linux / macOS:
./gradlew assembleDebug
./gradlew installDebug

# Windows (PowerShell / CMD):
.\gradlew.bat assembleDebug
.\gradlew.bat installDebug
```

Собранный установочный пакет формируется по пути:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

### Сборка Release APK

```bash
./gradlew assembleRelease
```

В конфигурации release активирована оптимизация R8 для библиотек `androidx.**`, `kotlin.**` и `kotlinx.**`, а также включены keep-правила для JNI-библиотек MediaPipe Tasks (`rules.keep`). Для распространения APK подпишите файл вашим release-ключом в соответствии с [официальным руководством по подписи](https://developer.android.com/studio/publish/app-signing).

## Использование и голосовой интерфейс

1. **Запуск и выдача разрешений**: при первом открытии приложение запрашивает доступ к камере и Bluetooth (`BLUETOOTH_CONNECT` на Android 12+). Если доступ к камере не предоставлен, отображается поясняющий экран с кнопкой повторного запроса.
2. **Активация сканера и панели статуса**: после предоставления доступа звучит фраза `"Камера активирована. Сканирование окружения запущено."` (либо `"Система Argus готова к работе."` при повторном запуске). В верхней части экрана отображаются:
   - плашки активных пространственных угроз;
   - карточки `"ДИСТАНЦИЯ ТРОСТИ"` и `"КУРС"`;
   - индикатор статуса связи (`"БЛЮТУЗ: ПОДКЛЮЧЕНО"`, `"БЛЮТУЗ: ПОИСК HC-05..."`, `"БЛЮТУЗ: ДЕМО"`, `"БЛЮТУЗ: НЕТ СВЯЗИ"`);
   - кнопка `"ТЕСТ / КАЛИБРОВКА"` для переподключения сопряженной трости или запуска локальной демонстрации.
3. **Навигация**: держите телефон вертикально задней камерой вперед по направлению движения. На экране отображаются контуры обнаруженных объектов с цветовой дифференциацией:
   - **Красный контур**: объект прямо по курсу движения (зона Center);
   - **Желтый контур**: объект на левом фланге (зона Left);
   - **Зеленый контур**: объект на правом фланге (зона Right);
   - **Голубой контур**: мебель, диван, кресло или подлокотник.

### Единая 5-уровневая таблица приоритетов и голосовых фраз

Предупреждения оцениваются в каждом цикле обработки кадра и при критических пакетах телеметрии. Озвучивается **условие с наивысшим приоритетом**:

| Приоритет | Ситуация | Голосовое сообщение | Срочность (прерывание) |
|:---:|:---|:---|:---:|
| **1** | **Сонар трости `< 35 см` ИЛИ `StairsAhead`** | `"Внимание, близко препятствие: XX см!"` / `"Осторожно, впереди лестница!"` | **Да** (мгновенно прерывает речь) |
| **2** | **Боковой Sensor Fusion** (`LEFT`/`RIGHT` + объект в той же зоне) | `"Осторожно, слева преграда!"` / `"Осторожно, справа преграда!"` | **Да** (мгновенно прерывает речь) |
| **3** | **`WallProximity` ИЛИ близкий объект `NEAR` (`>= 28%`) по центру** | `"Внимание, стена прямо по курсу!"` / `"Вплотную, <объект>!"` | **Да** (мгновенно прерывает речь) |
| **4** | **`ArmrestDetected` ИЛИ `DoorAhead`** | `"Подлокотник <слева/справа/впереди>"` / `"Впереди дверной проем"` | **Нет** (дожидается паузы речи) |
| **5** | **Препятствие `MEDIUM` (`12%-28%`) по центру с анализом коридора** | `"Прямо <объект>, обойдите слева"` / `"Прямо <объект>, обойдите справа"` / `"Впереди <объект>"` | **Нет** (фоновое информирование) |

> **Перевод объектов и дедупликация:** 10 целевых классов COCO переводятся на русский язык через `ObstacleTranslator` (например: `person` -> `"человек"`, `chair` -> `"стул"`, `dining table` -> `"стол"`, `potted plant` -> `"цветок"`). Одинаковые фразы в `AndroidVoiceAlertService` подавляются на 4 секунды (`SAME_TEXT_COOLDOWN_MS = 4000L`).

### Пространственные зоны и оценка дистанции

- **Горизонтальные зоны (`HorizontalZone`)**: вычисляются по горизонтальному центру рамки объекта (`centerX`):
  - `LEFT`: центр рамки левее 33% ширины кадра;
  - `CENTER`: центр рамки в диапазоне от 33% до 66% ширины кадра;
  - `RIGHT`: центр рамки правее 66% ширины кадра.
- **Категории дистанции (`DistanceCategory`)**: так как на смартфонах без ToF датчика отсутствует прямое измерение глубины, дистанция рассчитывается эвристически по доле площади кадра, занимаемой объектом:
  - `NEAR` (близко): объект занимает **>= 28%** площади кадра (`>= 0.28`);
  - `MEDIUM` (средняя дистанция): объект занимает **от 12% до 28%** площади кадра (`0.12 <= area < 0.28`);
  - `FAR` (далеко): объект занимает **от 6% до 12%** площади кадра (`0.06 <= area < 0.12`, учитывается без прямой озвучки);
  - Менее **6%** площади кадра: объект игнорируется.

### Классификация опасностей и дедупликация речи

1. **Лестницы и ступени**: распознаются по меткам `stair`, `step`, `tread` (уверенность >= 0.65). Для исключения ложных тревог лестница подтверждается только при совпадении на двух последовательных кадрах в окне 750 мс.
2. **Диваны, кресла и подлокотники**: метки `chair`, `couch`, `sofa`, `furniture`, `armrest` имеют приоритет над лестницами, предотвращая ошибочное распознавание полосатой обивки мебели как ступеней.
3. **Глухие стены**: метка `wall` (уверенность >= 0.65) подтверждается только при отсутствии на переднем плане физических объектов с четкими bounding box.
4. **Фильтрация повторов речи**: одинаковые фразы блокируются на 4 секунды (`SAME_TEXT_COOLDOWN_MS = 4000L`), предотвращая зацикливание голосового помощника при неподвижном положении пользователя.

## Архитектура

Проект построен по принципам **Clean Architecture** и **UDF (Unidirectional Data Flow)**:
- **UI-слой** подписывается на неизменяемый поток состояния `MainUiState`.
- **Domain-слой** не имеет зависимостей от Android SDK и оперирует чистыми интерфейсами (`SpeechOutput`, `CaneBluetoothClient`, `VisionProcessor`, `AlertStrategy`).
- **Data-слой** инкапсулирует работу с нативными библиотеками машинного зрения, односторонним Bluetooth SPP и системным сервисом Android TTS.

## Разрешения Android

| Разрешение | Назначение | Используется в текущей версии |
|:---|:---|:---:|
| `android.permission.CAMERA` | Видеопоток для нейросетевого распознавания | **Да** (запрашивается в runtime) |
| `android.permission.VIBRATE` | Тактильный виброотклик смартфона при опасности | Задекларировано для следующего релиза |
| `android.permission.BLUETOOTH_CONNECT` | Подключение к трости по Bluetooth SPP (Android 12+) | **Да** (запрашивается в runtime) |
| `android.permission.BLUETOOTH_SCAN` | Поиск трости с флагом `neverForLocation` (Android 12+) | Задекларировано в манифесте |
| `android.permission.BLUETOOTH` / `ADMIN` | Подключение к трости на Android 10-11 (`maxSdkVersion=30`) | **Да** (для старых версий Android) |

> 🔒 **Приложение принципиально не запрашивает разрешение `android.permission.INTERNET`**, что гарантирует невозможность отправки пользовательских данных в сеть.

## Конфиденциальность и безопасность

- **100% On-Device Processing**: нейросети EfficientDet-Lite0 и ML Kit работают исключительно на локальном процессоре (CPU/NNAPI) устройства.
- **Отсутствие записи**: видеокадры обрабатываются напрямую в буфере оперативной памяти (`ImageProxy` / `Bitmap`) и немедленно освобождаются после анализа. Изображения не сохраняются в галерею и во временные файлы.
- **Отказоустойчивость**: приложение разработано как независимый ассистент. В случае потери связи со смартфоном трость Argus продолжает автономную работу на базе ультразвукового сонара и вибромотора ручки.
