# 📱 Argus Android Application

> Автономный мобильный ассистент компьютерного зрения для незрячих и слабовидящих пользователей на базе CameraX, MediaPipe Tasks и ML Kit.

Android-приложение системы **Argus** в реальном времени анализирует видеопоток с камеры смартфона, распознает физические препятствия (80 классов COCO) и опасные элементы окружения (лестницы, стены, дверные проемы, мебель и подлокотники) и озвучивает естественные голосовые подсказки.

Все нейросетевые вычисления и геометрическая фильтрация выполняются **локально на устройстве** без обращения к внешним серверам и без необходимости подключения к интернету. Приложение входит в состав общего репозитория Argus и может работать как самостоятельно, так и в паре с аппаратной тростью.

## Возможности

- **Обработка потока в реальном времени**: анализ кадров с адаптивным пропуском при отставании (`STRATEGY_KEEP_ONLY_LATEST`) с частотой около 5-6 кадров в секунду для экономии батареи.
- **Детекция 80 классов COCO**: точное определение людей, автомобилей, стульев, столов, бутылок и других бытовых препятствий с координатами bounding box вместо обобщенных категорий.
- **Разделение на пространственные зоны**: классификация препятствий по горизонтальным секторам (слева, по центру, справа) и трем категориям дистанции (близко, средняя дистанция, далеко).
- **Распознавание опасных элементов инфраструктуры**: специализированный детектор лестниц, глухих стен, открытых дверных проемов и посадочных мест (кресла, диваны, подлокотники).
- **Строгая иерархия безопасности**: срочные навигационные сигналы (лестница, стена) мгновенно прерывают текущую фразу синтезатора речи.
- **Защита от ложных срабатываний**: двухкадровое подтверждение лестниц в окне 750 мс, подавление стен при наличии объектов на переднем плане и приоритет мебели над лестничными ступенями.
- **Полная автономность и приватность**: нулевой сетевой трафик, локальная обработка кадров в оперативной памяти без записи на диск.

## Установка и запуск

### Android Studio

1. Откройте каталог `android/` через меню **File → Open**.
2. Дождитесь окончания синхронизации Gradle и загрузки зависимостей.
3. Подключите реальное Android-устройство по USB (включите режим «Отладка по USB» в настройках разработчика) либо запустите эмулятор с эмуляцией задней камеры (**VirtualScene** или **Webcam**).
4. Выберите модуль `app` в списке конфигураций и нажмите **Run** (`Shift + F10`).

### Командная строка

Сборка Debug APK и установка на подключенное устройство:

```bash
# Перейдите в каталог проекта
cd android

# Linux / macOS:
./gradlew assembleDebug
./gradlew installDebug

# Windows (PowerShell / CMD):
.\gradlew.bat assembleDebug
.\gradlew.bat installDebug
```

Собранный установочный пакет формируется по пути:
```
android/app/build/outputs/apk/debug/app-debug.apk
```

### Сборка Release APK

```bash
./gradlew assembleRelease
```

В конфигурации release активирована оптимизация R8 для библиотек `androidx.**`, `kotlin.**` и `kotlinx.**`, а также включены keep-правила для JNI-библиотек MediaPipe Tasks (`rules.keep`). Для распространения APK подпишите файл вашим release-ключом в соответствии с [официальным руководством по подписи](https://developer.android.com/studio/publish/app-signing).

## Использование и голосовой интерфейс

1. **Запуск и выдача разрешений**: при первом открытии приложение запрашивает доступ к камере. Если доступ не предоставлен, отображается поясняющий экран с кнопкой повторного запроса, а голосовой движок произносит подсказку.
2. **Активация сканера**: после предоставления доступа звучит фраза `Camera activated. Environmental scan started.` и запускается цикл анализа.
3. **Навигация**: держите телефон вертикально задней камерой вперед по направлению движения. На экране отображаются контуры обнаруженных объектов с цветовой дифференциацией:
   - 🔴 **Красный контур**: объект прямо по курсу движения (зона Center);
   - 🟡 **Желтый контур**: объект на левом фланге (зона Left);
   - 🟢 **Зеленый контур**: объект на правом фланге (зона Right);
   - 🔵 **Голубой контур**: мебель, диван, кресло или подлокотник.

### Таблица приоритетов и голосовых фраз

Предупреждения оцениваются каждый цикл. Озвучивается **первое совпавшее условие с наивысшим приоритетом**:

| Приоритет | Ситуация | Голосовое сообщение | Срочность (прерывание) |
|:---:|:---|:---|:---:|
| **1** | **Лестница впереди** | `Caution, stairs ahead!` | **Да** (мгновенно прерывает текущую речь) |
| **2** | **Глухая стена по курсу** | `Warning, wall directly ahead!` | **Да** (мгновенно прерывает текущую речь) |
| **3** | **Подлокотник или место для сидения** | `Armrest on the left`<br>`Armrest on the right`<br>`Armrest ahead` | **Нет** (дожидается паузы речи) |
| **4** | **Дверной проем** | `Doorway ahead` | **Нет** (дожидается паузы речи) |
| **5** | **Близкое препятствие по центру** | `Careful, <объект> right ahead` | **Нет** (высокий информационный приоритет) |
| **6** | **Препятствие средней дистанции** | `<Объект> ahead` | **Нет** (фоновое информирование) |

> **Примечание по естественности речи:** названия объектов в середине фразы произносятся в естественном нижнем регистре (например: *«Careful, chair right ahead»*, *«Careful, person right ahead»*), кроме аббревиатуры `TV` (*«Careful, TV right ahead»*). Для многозначных меток COCO применены разговорные замены: `mouse` → *«computer mouse»*, `remote` → *«remote control»*, `sports ball` → *«ball»*, `hair drier` → *«hair dryer»*.

### Пространственные зоны и оценка дистанции

- **Горизонтальные зоны (`HorizontalZone`)**: вычисляются по горизонтальному центру рамки объекта (`centerX`):
  - `LEFT`: центр рамки левее 33% ширины кадра;
  - `CENTER`: центр рамки в диапазоне от 33% до 66% ширины кадра;
  - `RIGHT`: центр рамки правее 66% ширины кадра.
- **Категории дистанции (`DistanceCategory`)**: так как на смартфонах без ToF датчика отсутствует прямое измерение глубины, дистанция рассчитывается эвристически по доле площади кадра, занимаемой объектом:
  - `NEAR` (близко): объект занимает **более 35%** площади кадра;
  - `MEDIUM` (средняя дистанция): объект занимает **от 10% до 35%** площади кадра;
  - `FAR` (далеко): объект занимает **менее 10%** площади кадра (не вызывает звуковых тревог).

### Классификация опасностей и дедупликация речи

1. **Лестницы и ступени**: распознаются по меткам `stair`, `step`, `tread` (уверенность ≥ 0.65). Для исключения ложных тревог лестница подтверждается только при совпадении на двух последовательных кадрах в окне 750 мс.
2. **Диваны, кресла и подлокотники**: метки `chair`, `couch`, `sofa`, `furniture`, `armrest` имеют приоритет перед лестницами, предотвращая ошибочное распознавание полосатой обивки мебели как ступеней.
3. **Глухие стены**: метка `wall` (уверенность ≥ 0.65) подтверждается только при отсутствии на переднем плане физических объектов с четкими bounding box.
4. **Фильтрация повторов речи**: одинаковые некритические подсказки блокируются интервалом от 1.5 до 4.0 секунд, предотвращая зацикливание голосового помощника при неподвижном положении пользователя.

## Архитектура

Проект построен по принципам **Clean Architecture** и **UDF (Unidirectional Data Flow)**:
- **UI-слой** подписывается на неизменяемый поток состояния `MainUiState`.
- **Domain-слой** не имеет зависимостей от Android SDK и оперирует чистыми интерфейсами (`SpeechOutput`, `VisionProcessor`, `AlertStrategy`).
- **Data-слой** инкапсулирует работу с нативными библиотеками машинного зрения и системным сервисом Android TTS.

## Разрешения Android

| Разрешение | Назначение | Используется в текущей версии |
|:---|:---|:---:|
| `android.permission.CAMERA` | Видеопоток для нейросетевого распознавания | **Да** (запрашивается в runtime) |
| `android.permission.VIBRATE` | Тактильный виброотклик смартфона при опасности | Задекларировано для следующего релиза |
| `android.permission.BLUETOOTH_CONNECT` | Подключение к трости по Bluetooth SPP (Android 12+) | Задекларировано для интеграции HC-05 |
| `android.permission.BLUETOOTH_SCAN` | Поиск трости с флагом `neverForLocation` (Android 12+) | Задекларировано для интеграции HC-05 |
| `android.permission.BLUETOOTH` / `ADMIN` | Подключение к трости на Android 10-11 (`maxSdkVersion=30`) | Задекларировано для совместимости |

> 🔒 **Приложение принципиально не запрашивает разрешение `android.permission.INTERNET`**, что гарантирует невозможность отправки пользовательских данных в сеть.

## Конфиденциальность и безопасность

- **100% On-Device Processing**: нейросети EfficientDet-Lite0 и ML Kit работают исключительно на локальном процессоре (CPU/NNAPI) устройства.
- **Отсутствие записи**: видеокадры обрабатываются напрямую в буфере оперативной памяти (`ImageProxy` / `Bitmap`) и немедленно освобождаются после анализа. Изображения не сохраняются в галерею и во временные файлы.
- **Отказоустойчивость**: приложение разработано как независимый ассистент. В случае потери связи со смартфоном трость Argus продолжает автономную работу на базе ультразвукового сонара и вибромотора ручки.

| Тестовый класс | Тип | Что верифицируется |
