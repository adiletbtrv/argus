# P0000: Кнопка и Светодиод (Button + LED)

## Описание

Базовый аппаратный прототип проверки цифрового ввода-вывода на микроконтроллере в симуляторе Tinkercad:
- **Проверка цифрового входа (`INPUT_PULLUP`):** считывание состояния тактовой кнопки без внешнего подтягивающего резистора (в покое на пине держится `HIGH`, при нажатии замыкается на `GND` и переходит в `LOW`).
- **Проверка цифрового выхода (`OUTPUT`):** управление светодиодным индикатором в зависимости от состояния кнопки.
- **Отправная точка цепочки прототипов (`P0000–P0007`):** базовый стенд для отработки логики сигналов перед подключением датчиков расстояния, силовых ключей и модулей индикации.

---

## Схема подключения

![Схема P0000](P0000.png)


Arduino Uno 

│

├─── Пин D2 (INPUT_PULLUP) ──── [ Кнопка (Pushbutton) ] ──── GND

│

└─── Пин D13 (OUTPUT) ─────── [ Резистор / Светодиод (LED) ] ──── GND

---

### Таблица соединений:
| Пин Arduino Uno | Компонент / Вывод | Назначение |
|:---|:---|:---|
| `D2` | Кнопка (Pushbutton) | Цифровой вход с внутренней подтяжкой к питанию (`INPUT_PULLUP`) |
| `GND` | Кнопка (второй контакт), LED (катод) | Общая земля схемы |
| `D13` | Светодиод (LED, анод через токоограничивающий резистор) | Цифровой выход индикации (`OUTPUT`) |

---

## Исходный код (C++)

```cpp
void setup() {
  pinMode(2, INPUT_PULLUP); 
  pinMode(13, OUTPUT);       
}

void loop() {
  if (digitalRead(2) == LOW) {
    digitalWrite(13, HIGH);  
  } else {
    digitalWrite(13, LOW);   
  }
}
