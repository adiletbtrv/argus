# P0006: Делитель напряжения 5В → 3.3В + Односторонняя передача Bluetooth телеметрии HC-05

## Описание

Прототип узла беспроводной связи трости **Argus** со смартфоном, решающий две важнейшие задачи надежности и безопасности:
1. **Согласование логических уровней (5V TTL → 3.3V LVTTL):** вход `RXD` радиомодуля HC-05 рассчитан на напряжение не более 3.3 В. Подача 5 В с выхода микроконтроллера напрямую приводит к деградации и пробою чипа Bluetooth. Узел реализует делитель напряжения на резисторах 1 кОм и 2 кОм.
2. **Строго односторонний протокол (трость → телефон):**
   - Линия `TXD` модуля HC-05 аппаратно не подключается;
   - В коде конструктор `SoftwareSerial btSerial(10, 11)` требует пин RX, однако в функции `setup()` сразу же вызывается `btSerial.stopListening()`. Прерывания на прием отключаются, встроенная подтяжка удерживает пин в HIGH;
   - Никакие внешние помехи, попытки несанкционированного доступа или сбои приложения на телефоне не могут заблокировать работу сонара и вибромотора трости.

## Расчет согласующего резистивного делителя

Схема делителя напряжения на линии TX Arduino (D11):

```
Arduino D11 (TX 5V) ───[ R1: 1 кОм ]───┬───> RX HC-05 (3.3V Logic)
                                        │
                                   [ R2: 2 кОм ]
                                        │
                                       GND
```

Формула расчета выходного напряжения:

$$V_{out} = V_{in} \cdot \frac{R_2}{R_1 + R_2} = 5.0\,\text{В} \cdot \frac{2000\,\text{Ом}}{1000\,\text{Ом} + 2000\,\text{Ом}} = 5.0\,\text{В} \cdot \frac{2}{3} \approx 3.33\,\text{В}$$

Ток, потребляемый делителем при логической единице:
$$I = \frac{5.0\,\text{В}}{3000\,\text{Ом}} \approx 1.67\,\text{мА}$$
Это абсолютно безопасно для вывода ATmega328P (предел 40 мА) и обеспечивает крутые фронты импульсов на скорости 9600 бод.

## Формат протокола телеметрии

Трость транслирует наружу структурированные текстовые пакеты вида:
```text
DIST:<дистанция_см>,DIR:<направление>\n
```

Примеры валидных пакетов:
* `DIST:45,DIR:CENTER` — препятствие на расстоянии 45 см, трость направлена прямо;
* `DIST:30,DIR:LEFT` — препятствие на 30 см, обнаружен наклон трости влево;
* `DIST:120,DIR:RIGHT` — дистанция 120 см, наклон вправо.

---

## Схема подключения

| Пин Nano | Компонент | Назначение |
|:---|:---|:---|
| D11 | Резистор R1 (1 кОм) | Программный TX (SoftwareSerial, 5V) |
| - | Точка соединения R1 и R2 | Выход делителя 3.33V (подключается к RXD HC-05) |
| GND | Резистор R2 (2 кОм) | Нижнее плечо делителя на землю схемы |
| D0 / D1 | USB Serial | Аппаратный UART свободен для отладки и загрузки прошивки |

## Исходный код (C++)

```cpp
#include <SoftwareSerial.h>

const int BT_RX_PIN = 10;
const int BT_TX_PIN = 11;

SoftwareSerial btSerial(BT_RX_PIN, BT_TX_PIN);

void setup() {
  Serial.begin(9600);
  btSerial.begin(9600);

  // Односторонний режим: отключаем прием
  btSerial.stopListening();

  Serial.println(F("Argus P0006: Level Shifter & Telemetry Testbench"));
}

void loop() {
  // Передача пакета на смартфон через согласованный делитель
  btSerial.print(F("DIST:45,DIR:CENTER\n"));

  Serial.println(F("[TX HC-05 3.3V] Sent: DIST:45,DIR:CENTER"));
  delay(1000);
}
```

## Сценарий тестирования

1. Запустите симуляцию Wokwi.
2. В Serial Monitor выводятся логи отправляемых пакетов телеметрии с подтверждением безопасного уровня напряжения 3.33V.
3. Зеленый индикатор данных на выходе делителя импульсно мигает в такт передаваемым байтам UART.
4. Скорость передачи 9600 бод обеспечивает высокую помехоустойчивость даже при слабом заряде аккумулятора.

### В среде VS Code (Wokwi Simulator)
1. Установите расширение Wokwi Simulator.
2. Откройте файл `diagram.json`.
3. Нажмите кнопку ▶ (**Start Simulator**) в панели редактора.
4. Прошивка (`build/main.ino.hex`) запускается автоматически из коробки.
