# P0004: Дешифратор 74HC138 + Светодиоды поворотников (Active LOW)

## Описание

Аппаратный прототип проверки подсистемы индикации направления трости **Argus** на базе 3-to-8 КМОП-дешифратора **74HC138**:
- **Аппаратная взаимоблокировка:** дешифратор физически держит активным только один выход. Левый и правый сигналы не могут включиться одновременно ни при каких сбоях микроконтроллера.
- **Инверсные выходы (Active LOW):** светодиоды подключены по схеме с втекающим током (Current Sinking) — аноды подключены к шине +5V через токоограничивающие резисторы 470 Ом, а катоды коммутируются выходами `/Y1` и `/Y2`.
- **Экономия пинов контроллера:** 3 линии GPIO (D2/D3/D4) позволяют адресовать до 8 независимых состояний (для трости задействованы нейтраль `Y0`, лево `Y1`, право `Y2`, резерв `Y3`).

---

## Схема подключения

```
+5V Rail
   │
   ├───[ 470 Ом ]───(A ─►|─ K)───> Пин 14 (/Y1) 74HC138 [LED LEFT - Оранжевый]
   │
   └───[ 470 Ом ]───(A ─►|─ K)───> Пин 13 (/Y2) 74HC138 [LED RIGHT - Желтый]
```

### Таблица соединений:
| Пин Nano | Пин 74HC138 | Назначение |
|:---|:---|:---|
| 5V | 16 (VCC), 6 (G1) | Питание логики и прямой вход разрешения (Enable HIGH) |
| GND | 8 (GND), 4 (/G2A), 5 (/G2B) | Общая земля и инверсные входы разрешения (Enable LOW) |
| D2 | 1 (A) | Адресный бит 0 (LSB) |
| D3 | 2 (B) | Адресный бит 1 |
| D4 | 3 (C) | Адресный бит 2 (MSB, фиксирован LOW) |
| - | 14 (/Y1) | Катод LED LEFT (поворот влево) |
| - | 13 (/Y2) | Катод LED RIGHT (поворот вправо) |

---

## Таблица состояний (согласно docs/truth_table.md)

| C (D4) | B (D3) | A (D2) | Активный выход | Состояние LED | Состояние трости |
|:---:|:---:|:---:|:---:|:---:|:---|
| `0` | `0` | `0` | `/Y0` (LOW) | Все выключены | **Прямо (CENTER)** — нейтральное положение |
| `0` | `0` | `1` | `/Y1` (LOW) | **LED LEFT ВКЛ** | **Поворот влево (LEFT)** |
| `0` | `1` | `0` | `/Y2` (LOW) | **LED RIGHT ВКЛ** | **Поворот вправо (RIGHT)** |
| `0` | `1` | `1` | `/Y3` (LOW) | Все выключены | **Резервный канал (NC)** |

## Исходный код (C++)

```cpp
const int PIN_A = 2; // Адресный вход A (бит 0, LSB)
const int PIN_B = 3; // Адресный вход B (бит 1)
const int PIN_C = 4; // Адресный вход C (бит 2, MSB)

void setAddress(int c, int b, int a) {
  digitalWrite(PIN_C, c ? HIGH : LOW);
  digitalWrite(PIN_B, b ? HIGH : LOW);
  digitalWrite(PIN_A, a ? HIGH : LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_A, OUTPUT);
  pinMode(PIN_B, OUTPUT);
  pinMode(PIN_C, OUTPUT);
  setAddress(0, 0, 0); // Нейтраль
}

void loop() {
  // STATE 0: CENTER
  setAddress(0, 0, 0);
  Serial.println(F("[STATE 0] CBA=000 -> /Y0 Active -> CENTER (LEDs OFF)"));
  delay(2000);

  // STATE 1: LEFT
  setAddress(0, 0, 1);
  Serial.println(F("[STATE 1] CBA=001 -> /Y1 Active -> LEFT TURN (LED LEFT ON)"));
  delay(2000);

  // STATE 2: RIGHT
  setAddress(0, 1, 0);
  Serial.println(F("[STATE 2] CBA=010 -> /Y2 Active -> RIGHT TURN (LED RIGHT ON)"));
  delay(2000);

  // STATE 3: RESERVE
  setAddress(0, 1, 1);
  Serial.println(F("[STATE 3] CBA=011 -> /Y3 Active -> RESERVE"));
  delay(2000);
}
```

## Сценарий тестирования

1. Запустите симуляцию Wokwi.
2. В Serial Monitor выводятся шаги смены состояний каждые 2 секунды.
3. В состоянии 0 (`CBA=000`) оба светодиода выключены.
4. В состоянии 1 (`CBA=001`) загорается оранжевый светодиод (LED LEFT).
5. В состоянии 2 (`CBA=010`) оранжевый гаснет, загорается желтый светодиод (LED RIGHT).
6. В состоянии 3 (`CBA=011`) оба светодиода выключены.
