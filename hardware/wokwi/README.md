# Прототипы симуляции в Wokwi (P0004 – P0007)

В данном каталоге собраны интерактивные программно-аппаратные прототипы умной трости **Argus** в симуляторе [Wokwi](https://wokwi.com).

В отличие от базовых электротехнических схем Tinkercad (P0000–P0003), стенды Wokwi воспроизводят цифровую логику, работу кастомных КМОП-микросхем, математические алгоритмы фильтрации и комплексную интеграцию компонентов.

## Архитектура сквозной верификации

Разработка трости разделена на непрерывную последовательность шагов без логических разрывов:

```
[Базовый ввод-вывод]
  P0000 (Tinkercad): Кнопка + Светодиод (GPIO digitalRead / digitalWrite)
      │
[Эхолокация и дистанция]
  P0001 (Tinkercad): Сонар HC-SR04 + LED (замер времени pulseIn, порог 20 см)
      │
[Силовая тактильная индикация]
  P0002 (Tinkercad): Сонар + NPN транзистор + Вибромотор (силовой ключ, гасящий диод)
      │
[Автономное управление питанием]
  P0003 (Tinkercad): Сонар + Вибромотор + Тумблер разрыва питания
      │
[Цифровая аппаратная коммутация]
  P0004 (Wokwi): Дешифратор 74HC138 + светодиоды поворотников (Active LOW)
      │
[Математика и фильтрация крена]
  P0005 (Wokwi): Потенциометр крена + алгоритм гистерезиса 25°/17° и удержания 250 мс
      │
[Согласование уровней и связь]
  P0006 (Wokwi): Резистивный делитель 5V->3.3V (1k/2k) + односторонняя телеметрия HC-05
      │
[Интеграционный финал]
  P0007 (Wokwi): Полный интерактивный стенд всех систем Argus Cane
```

## Как запускать симуляции

### Вариант 1: В среде VS Code (Wokwi Simulator Extension)
1. Установите официальное расширение [Wokwi Simulator](https://marketplace.visualstudio.com/items?itemName=Wokwi.wokwi-vscode).
2. Перейдите в каталог нужного прототипа (например, `argus/hardware/wokwi/P0004` или `P0007`).
3. Откройте файл `diagram.json`.
4. Нажмите сочетание клавиш `Ctrl + Shift + P` → **Wokwi: Start Simulator** (или кнопку ▶ в заголовке редактора).

### Вариант 2: В веб-браузере на Wokwi.com
1. Откройте [wokwi.com](https://wokwi.com/arduino/new?template=arduino-nano).
2. Скопируйте содержимое `diagram.json` выбранного прототипа на вкладку схемы.
3. Скопируйте код `main.ino` (и вспомогательные файлы, если требуются) во вкладку скетча.
4. Нажмите кнопку **Play**.

### Пересборка бинарников (при модификации исходников)

В каталоге `hardware/wokwi/` подготовлен скрипт `build.ps1` для автоматической компиляции:
```powershell
# Собрать все прототипы (P0004..P0007) и WASM-чип
powershell -ExecutionPolicy Bypass -File build.ps1 all

# Собрать конкретный прототип (например, P0007)
powershell -ExecutionPolicy Bypass -File build.ps1 P0007
```
