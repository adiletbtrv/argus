# Wokwi: интерактивный стенд Argus

Полная симуляция работы трости в браузере без физического железа.
Стенд использует ту же логику классификации направления (`direction_logic`), что и реальная прошивка, но с упрощенной обвязкой.

## Отличия от реальной платы

| Реальное железо | Замена в Wokwi | Почему |
|:---|:---|:---|
| MPU6050 (гироскоп/акселерометр) | Потенциометр на A0 | Проще управлять углом крена, MPU6050 оставлен на схеме как визуальная ссылка |
| Вибромотор (PWM D9) | Пьезодинамик (D11) | Звуковой сигнал наглядно показывает срабатывание тактильного отклика |
| Дешифратор 74HC138 (D2/D3/D4) | 3 светодиода (D8/D9/D10) | В Wokwi нет 74HC138, прямое подключение LED нагляднее |
| Bluetooth HC-05 (TX D11) | Serial Monitor | Телеметрия TILT/DIR/DIST выводится в терминал |

## Таблица пинов стенда

| Пин Nano | Компонент | Назначение |
|:---|:---|:---|
| D2 | Кнопка (INPUT_PULLUP) | Зарезервирована под калибровку (issue #11) |
| D4 | HC-SR04 TRIG | Запуск измерения расстояния |
| D5 | HC-SR04 ECHO | Прием эхо-импульса |
| D8 | LED (зеленый) | Индикация LEFT |
| D9 | LED (желтый) | Индикация CENTER |
| D10 | LED (синий) | Индикация RIGHT |
| D11 | Buzzer | Звуковой сигнал при препятствии < 50 см |
| D13 | Встроенный LED | Индикация нажатия кнопки |
| A0 | Потенциометр | Имитация крена трости (-45..+45 градусов) |
| A4 (SDA) | MPU6050 | Подключен, но в скетче не используется |
| A5 (SCL) | MPU6050 | Подключен, но в скетче не используется |

## Как запустить

### В браузере (Wokwi Web)
1. Откройте [wokwi.com](https://wokwi.com) и создайте новый проект Arduino Nano.
2. Замените содержимое `diagram.json` на файл из этой папки.
3. Скопируйте `sketch.ino`, `direction_logic.h` и `direction_logic.cpp` как вкладки.
4. Нажмите Play.

### В VS Code (расширение Wokwi)
1. Установите расширение [Wokwi Simulator](https://marketplace.visualstudio.com/items?itemName=Wokwi.wokwi-vscode).
2. Откройте папку `hardware/wokwi/` как рабочую директорию.
3. Нажмите Ctrl+Shift+P -> "Wokwi: Start Simulator".

## Сценарий тестирования

1. **Старт:** в Serial Monitor появится `ARGUS CANE SIMULATOR STARTED`.
2. **Крен:** покрутите потенциометр (слева вверху). При повороте за 25 градусов и удержании дольше 250 мс загорится LEFT или RIGHT. При возврате ниже 17 градусов загорится CENTER (гистерезис).
3. **Препятствие:** нажмите на HC-SR04 и двигайте ползунок расстояния. При значении меньше 50 см пьезодинамик подаст звуковой сигнал.
4. **Кнопка:** при нажатии на желтую кнопку загорится встроенный LED на плате (D13).
5. **Телеметрия:** в Serial Monitor каждые 150 мс появляются строки `TILT:<угол>,DIR:<направление>,DIST:<расстояние> cm`.
