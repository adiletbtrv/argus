# Интерактивный симулятор Wokwi для Argus Smart Cane

В этом каталоге собраны файлы конфигурации для интерактивной симуляции аппаратной части умной трости Argus в симуляторе [Wokwi](https://wokwi.com/).

Стенд позволяет протестировать совместную работу датчиков, алгоритма определения поворота трости и реакцию виброотклика без физической сборки макета.

---

## 1. Назначение стенда и отличие от макетов Tinkercad

Ранее в проекте использовались базовые макеты Tinkercad (каталоги `hardware/tinkercad/P0000-P0003`):
- **P0000-P0003 в Tinkercad:** изолированные прототипы отдельных подсистем (проверка работы сонара, тактильного вибромотора, тумблера). В Tinkercad нет поддержки I2C датчика MPU6050 и модульной архитектуры прошивки, поэтому там тестировались только простые однофайловые скетчи.
- **Стенд Wokwi:** комплексный симулятор всей системы в сборе. В нем запускается реальная прошивка `firmware/argus_cane/argus_cane.ino`, задействован I2C гироскоп/акселерометр MPU6050, рассчитываются углы крена, работает алгоритм фильтрации и гистерезиса, моделируется вибросигнал и вывод телеметрии.

## 2. Соответствие реального железа и компонентов Wokwi

| Узел системы | Реальное железо Argus | Компонент в Wokwi | Пины Arduino Nano | Примечание по симуляции |
|:---|:---|:---|:---|:---|
| Микроконтроллер | Arduino Nano (ATmega328P) | `wokwi-arduino-nano` | Все пины | Полное совпадение архитектуры и портов |
| Датчик расстояния | RCWL-9610A | `wokwi-hc-sr04` | Trig: D5, Echo: D6 | Полная программная совместимость по протоколу импульса |
| Датчик наклона | MPU6050 (GY-521, I2C 0x68) | `wokwi-mpu6050` | SDA: A4, SCL: A5 | Эмулирует углы и сырые данные акселерометра/гироскопа |
| Виброотклик | Вибромотор через NPN транзистор | `wokwi-buzzer` (пьезодинамик) | Сигнал: D9 (PWM), GND | В Wokwi нет модели вибромотора; зуммер наглядно воспроизводит ШИМ звуком |
| Индикация: Лево | Зеленый светодиод через 74HC138 | `wokwi-led` (green) + 220 Ом | Анод: D7, Катод: GND | Прямое подключение к выходу D7 в режиме WOKWI_SIMULATION |
| Индикация: Центр | Желтый светодиод через 74HC138 | `wokwi-led` (yellow) + 220 Ом | Анод: D8, Катод: GND | Прямое подключение к выходу D8 в режиме WOKWI_SIMULATION |
| Индикация: Право | Синий светодиод через 74HC138 | `wokwi-led` (blue) + 220 Ом | Анод: D12, Катод: GND | Прямое подключение к выходу D12 в режиме WOKWI_SIMULATION |
| Орган калибровки | Тактовая кнопка калибровки | `wokwi-pushbutton` | Пин 2 к D2, Пин 1 к GND | Подтянута к GND (резерв под issue #11) |
| Резервный датчик | Потенциометр угла наклона | `wokwi-potentiometer` | SIG: A0, VCC: 5V, GND | Дополнительный аналоговый орган ввода для тестов |

### Почему зуммер на D9 заменяет вибромотор:
В библиотеке стандартных компонентов Wokwi отсутствует модель вибромоторчика. Пьезодинамик (Buzzer), подключенный к ШИМ-выводу D9, издает характерный звуковой сигнал при появлении сигнала вибрации, что дает мгновенную обратную связь при тестировании.

### Почему светодиоды подключены к D7, D8, D12 вместо дешифратора 74HC138:
В реальной трости дешифратор 74HC138 экономит выводы микроконтроллера при масштабировании матрицы светодиодов. В симуляторе Wokwi нет готовой модели микросхемы 74HC138. Чтобы не перегружать проект кастомными симуляционными микросхемами (custom chips), в прошивку добавлен режим `#define WOKWI_SIMULATION`. В этом режиме светодиоды подключены напрямую к свободным пинам D7 (левый), D8 (нейтраль) и D12 (правый). Основная логика работы 74HC138 на пинах D2/D3/D4 сохранена в коде без изменений для реальной платы.

## 3. Пошаговый сценарий интерактивного тестирования

1. **Старт и автокалибровка MPU6050 (первые 2 секунды):**
   - Нажмите кнопку запуска симуляции.
   - В терминале Serial появится строка: `Argus Smart Cane: инициализация...`, а затем `Калибровка гироскопа и акселерометра MPU6050...`.
   - В этот момент нельзя двигать ползунки MPU6050: датчик рассчитывает нулевые смещения.
   - По завершении калибровки появится сообщение `Готово к работе.` и загорится желтый светодиод CENTER (D8).

2. **Проверка обнаружения препятствий через HC-SR04 (< 50 см):**
   - Нажмите на датчик расстояния HC-SR04 в окне симуляции.
   - Переместите ползунок расстояния меньше 50 см (например, на 30 см).
   - Пьезодинамик (Buzzer) на D9 начнет издавать непрерывный звуковой сигнал, подтверждая срабатывание виброотклика.
   - Переместите ползунок выше 50 см (например, 80 см): зуммер мгновенно замолчит.

3. **Проверка классификатора крена MPU6050 (порог 25 градусов, гистерезис 17 градусов):**
   - Нажмите на компонент MPU6050 на схеме.
   - Измените угол наклона по оси X (Roll):
     - Наклоните датчик влево более чем на 25 градусов: желтый светодиод погаснет, загорится зеленый LED LEFT (D7). В Serial появится лог: `[DIR] LEFT | Крен: ... deg`.
     - Начните возвращать датчик к нулю: благодаря гистерезису зеленый светодиод продолжит гореть до тех пор, пока наклон не станет меньше 17 градусов. При переходе порога 17 градусов индикация вернется в состояние CENTER (желтый LED).
     - Наклоните датчик вправо более чем на 25 градусов: загорится синий LED RIGHT (D12), в терминале появится запись `[DIR] RIGHT | Крен: ... deg`.

4. **Проверка телеметрии в терминале:**
   - При обнаружении препятствия ближе 50 см прошивка параллельно транслирует телеметрию в формате:
     `DIST:<см>,DIR:<направление>` (например, `DIST:35,DIR:LEFT`).
   - Если препятствий нет, передача по каналу Bluetooth не забивает эфир.

## 4. Инструкция по запуску симулятора

### Вариант А: Запуск в браузере (онлайн)
1. Откройте онлайн симулятор на [wokwi.com](https://wokwi.com/).
2. Создайте новый проект для **Arduino Nano**.
3. Скопируйте содержимое файла `diagram.json` во вкладку `diagram.json` в Wokwi.
4. Во вкладке `libraries.txt` укажите зависимость:
   ```text
   MPU6050_light
   ```
5. Вставьте исходный код из `firmware/argus_cane/argus_cane.ino` в главное окно скетча.
6. В строке 8 скетча раскомментируйте макрос:
   ```cpp
   #define WOKWI_SIMULATION
   ```
7. Нажмите кнопку **Start Simulation** (зеленый треугольник).

### Вариант Б: Запуск локально в VS Code
1. Установите расширение **Wokwi Simulator** в Visual Studio Code (из вкладки Extensions).
2. Активируйте лицензию Wokwi (бесплатный пробный или стандартный ключ через команду `Wokwi: Request a Free Trial`).
3. Убедитесь, что в файле `firmware/argus_cane/argus_cane.ino` активен макрос `#define WOKWI_SIMULATION`.
4. Откройте файл `hardware/wokwi/diagram.json` в редакторе VS Code.
5. Нажмите клавишу `F1` и выберите команду `Wokwi: Start Simulator` (либо нажмите значок запуска на схеме).
6. Симулятор скомпилирует скетч согласно настройкам `hardware/wokwi/wokwi.toml` и запустит интерактивную отладку.
