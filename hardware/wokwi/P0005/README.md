# P0005: Эмуляция угла крена + Алгоритм гистерезиса направления (DirectionClassifier)

## Описание

Прототип математической модели определения намерения поворота пользователя трости **Argus**:
- **Имитация датчика положения:** аналоговый потенциометр на пине A0 преобразует напряжение 0..5V в диапазон угла крена от -45° до +45° (эмулируя данные оси крена гироскопа/акселерометра MPU6050);
- **Фильтрация шума шагов:** кратковременные колебания трости при ходьбе продолжительностью менее 250 мс игнорируются, исключая ложные переключения;
- **Двухпороговый гистерезис:**
  - Вход в состояние поворота (LEFT / RIGHT) требует превышения порога **25°** с удержанием не менее **250 мс**;
  - Возврат в нейтральное положение (CENTER) происходит только при уменьшении угла ниже **17°**, предотвращая дребезг на границе;
- **Светодиодная индикация:**
  - Зеленый LED (D8) — поворот влево (`LEFT`);
  - Желтый LED (D9) — прямо (`CENTER`);
  - Синий LED (D10) — поворот вправо (`RIGHT`).

---

## Схема подключения

```
Potentiometer:
   VCC ──────> +5V
   GND ──────> GND
   SIG ──────> A0 (Nano)

LEDs (Active HIGH через токоограничивающие резисторы 220 Ом):
   D8  ───[ LED Green (LEFT) ]───[ 220 Ом ]───> GND
   D9  ───[ LED Yellow (CENTER) ]─[ 220 Ом ]───> GND
   D10 ───[ LED Blue (RIGHT) ]───[ 220 Ом ]───> GND
```

### Таблица соединений:
| Пин Nano | Компонент | Назначение |
|:---|:---|:---|
| A0 | Потенциометр (SIG) | Аналоговый сигнал угла крена (-45°..+45°) |
| 5V | Потенциометр (VCC) | Опорное напряжение питания датчика |
| GND | Потенциометр (GND), катоды LED | Общая земля схемы |
| D8 | Анод LED Green | Индикатор поворота влево (LEFT) |
| D9 | Анод LED Yellow | Индикатор прямолинейного движения (CENTER) |
| D10 | Анод LED Blue | Индикатор поворота вправо (RIGHT) |

## Параметры алгоритма классификации

| Параметр | Значение | Обоснование |
|:---|:---:|:---|
| `TILT_THRESHOLD_DEG` | **25.0°** | Угол явного намерения повернуть трость в сторону |
| `HYSTERESIS_DEG` | **8.0°** (возврат при **17.0°**) | Зона нечувствительности, исключающая мерцание светодиодов |
| `HOLD_TIME_MS` | **250 мс** | Длительность типичного шага незрячего — фильтрует естественное раскачивание |

## Исходный код (C++)

В скетче используется проверенный модуль `DirectionClassifier` из `direction_logic.h`:

```cpp
#include "direction_logic.h"

const int POT_PIN = A0;
const int LED_LEFT = 8;
const int LED_CENTER = 9;
const int LED_RIGHT = 10;

DirectionClassifier classifier;

void setup() {
  Serial.begin(115200);
  pinMode(LED_LEFT, OUTPUT);
  pinMode(LED_CENTER, OUTPUT);
  pinMode(LED_RIGHT, OUTPUT);
}

void loop() {
  int raw = analogRead(POT_PIN);
  float roll = ((float)raw / 1023.0f) * 90.0f - 45.0f;

  Direction dir = classifier.classify(roll, millis());
  // ... обновление LED и вывод телеметрии
}
```

## Сценарий тестирования

1. Запустите симуляцию Wokwi и откройте **Serial Monitor** (115200 бод).
2. Поверните ручку потенциометра в центр (A0 ≈ 2.5V, TILT ≈ 0°). Горит только желтый светодиод (CENTER).
3. Поверните потенциометр вправо так, чтобы угол превысил +25°:
   - В первые 200 мс продолжает гореть CENTER (работает фильтр удержания);
   - Спустя 250 мс желтый гаснет и зажигается синий светодиод (RIGHT).
4. Медленно возвращайте потенциометр к центру:
   - При угле 22° синий диод **продолжает гореть** (эффект гистерезиса);
   - Как только угол опустится ниже 17°, синий гаснет и снова загорается желтый (CENTER).
5. Повторите тест влево (угол < -25°): загорается зеленый светодиод (LEFT).

### В среде VS Code (Wokwi Simulator)
