## Как это устроено

1. **Автономность трости от телефона.**  
   Все основные функции работают прямо на плате Arduino: опрос гироскопа, переключение светодиодов, замер дистанции сонаром и виброотклик. Если телефон сядет или приложение зависнет, трость продолжит полноценно работать сама по себе.
2. **Фильтрация шагов (гистерезис + задержка).**  
   При обычной ходьбе человек качает трость из стороны в сторону. Чтобы светодиоды не мигали на каждый взмах, мы сделали программный фильтр: порог наклона 25°, минимальное удержание 250 мс, а возврат назад в центр - только при угле меньше 17° (гистерезис 8°).
3. **Аппаратная защита светодиодов (74HC138).**  
   Сигналы поворота подключены через дешифратор 74HC138. Микросхема физически не может включить два выхода одновременно: горит либо левый, либо правый, либо оба выключены.
4. **Вибрация на ручке и телеметрия.**  
   Ультразвуковой датчик RCWL-9610A (HC-SR04) меряет расстояние перед человеком. Если до препятствия меньше 50 см, Arduino включает вибромоторчик в ручке через транзисторный ключ (схема проверена в прототипе P0002). Заодно трость отправляет по Bluetooth строчку с дистанцией и направлением.

## Архитектура

Система состоит из трех аппаратных узлов на трости и мобильного приложения:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      МОБИЛЬНЫЙ КОНТУР (Android App)                    │
│   Прием телеметрии (SPP) ──► Отображение статуса, навигация, голос     │
└───────────────────────────────────▲────────────────────────────────────┘
                                    │ Bluetooth (SPP) -> ТОЛЬКО ИСХОДЯЩИЙ ПОТОК
                                    │ Telemetry: "DIST:<см>,DIR:<DIR>\n"
┌───────────────────────────────────┴────────────────────────────────────┐
│                        АППАРАТНАЯ ЧАСТЬ ТРОСТИ                         │
│                                                                        │
│  [1. ПОДСИСТЕМА НАПРАВЛЕНИЯ]                                           │
│  MPU6050 (IMU) ──I2C──► Arduino Nano ──D2..D4──► 74HC138 ──► Светодиоды│
│                                                                        │
│  [2. ПОДСИСТЕМА ДИСТАНЦИИ И ТАКТИЛЬНОГО ОТКЛИКА] (Прототип P0002)      │
│  RCWL-9610A ──D5/D6──► Arduino Nano ──D9 (PWM)──► NPN ──► Вибромотор   │
│                                                                        │
│  [3. ПОДСИСТЕМА ТЕЛЕМЕТРИИ]                                            │
│  Arduino Nano (D11 TX) ──[1k/2k]──► HC-05 (BT TXD)                     │
│                                                                        │
│  [ПИТАНИЕ]: 18650 Li-Ion (3.7V) ──► Battery Shield (Boost 5V) ──► +5V  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Определение направления:** датчик MPU6050 считывает крен трости, контроллер фильтрует шум шагов и передает двоичный код на входы 74HC138, который зажигает нужный поворотник.
2. **Дистанция и виброотклик:** ультразвуковой датчик RCWL-9610A (HC-SR04) сканирует пространство впереди. Если до преграды ближе 50 см, контроллер через ШИМ на D9 запускает вибромотор.
3. **Исходящая телеметрия:** при обнаружении препятствия Arduino шлет пакет `DIST:<см>,DIR:<CENTER|LEFT|RIGHT>\n` в модуль HC-05 (TX на D11) для смартфона.

## Связь по Bluetooth

Канал Bluetooth сделан строго односторонним (трость -> телефон):

- **Только передача:** трость передает наружу данные о дистанции и угле поворота.
- **Никаких команд снаружи:** трость ничего не слушает из радиоканала. В коде на входе RX сразу вызывается `stopListening()`, чтобы случайные помехи или пакеты не сбивали тайминги датчиков.
- **Безопасность:** если телефон разрядится, выключится или потеряет связь, светодиоды и вибрация на самой трости продолжат работать без пауз.

## Сборка и прошивка

### Нужные библиотеки Arduino:
- `Wire` (стандартная библиотека)
- `SoftwareSerial` (стандартная библиотека)
- `MPU6050_light` (ставится через Library Manager в Arduino IDE)

### Загрузка скетча:
1. Подключите Arduino Nano к компьютеру по USB.
2. Откройте файл `firmware/argus_cane/argus_cane.ino` в Arduino IDE.
3. Выберите плату **Arduino Nano**, процессор **ATmega328P** (или *Old Bootloader*) и соответствующий COM-порт.
4. Нажмите кнопку «Загрузить».
5. При включении держите трость вертикально и неподвижно 2-3 секунды, пока калибруется MPU6050.

## Тестирование

Классификатор наклонов написан на чистом C++ без привязки к железу Arduino, поэтому его можно запускать на компьютере:

### Сборка и запуск:

**GCC / Clang:**
```bash
cd firmware/direction_logic
g++ -std=c++11 test_direction_logic.cpp direction_logic.cpp -o test_runner
./test_runner
```

**MSVC:**
```cmd
cd firmware\direction_logic
cl /EHsc /std:c++17 test_direction_logic.cpp direction_logic.cpp /Fe:test_runner.exe
test_runner.exe
```

Что проверяют тесты:
- Нейтральный угол (0°) -> CENTER;
- Короткие покачивания при шаге (< 250 мс) -> фильтруются и не вызывают переключения;
- Устойчивый наклон (> 25°, удержание > 250 мс) -> переход в RIGHT / LEFT;
- Зона гистерезиса -> возврат в CENTER только при наклоне меньше 17°.
